# =============================================================================
# SGDES workflow — pip requirements
#
# Install order matters.  Follow the steps below rather than running
# `pip install -r requirements.txt` blindly, because:
#   - PyTorch must be installed from the CUDA-specific index URL.
#   - PyG wheels are pre-built per (torch_version, cuda_version, python_version).
#   - foldseek and seqkit are standalone binaries (see delta_env_setup.sh).
#   - TRILL (SGDES fork) and SPHERICAL require editable installs from local repos.
#
# Quick install (Delta / CUDA 12.1):
#   Step 1: pip install torch==2.4.0+cu121 torchvision==0.19.0+cu121 torchaudio==2.4.0+cu121 \
#               --index-url https://download.pytorch.org/whl/cu121
#   Step 2: install PyG wheels (see delta_env_setup.sh step 3b)
#   Step 3: pip install -r requirements.txt
#   Step 4: pip install -e $SGDES_DIR          # TRILL fork (editable)
#   Step 5: pip install -e $SPHERICAL_DIR[sgdes,dragon,dev]
#   Step 6: download foldseek GPU binary and seqkit (see delta_env_setup.sh steps 9-10)
#
# For a fully automated install use delta_env_setup.sh or bridges2_env_setup.sh.
# =============================================================================
